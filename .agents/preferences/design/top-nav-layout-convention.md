# Top navigation layout convention

Preferred top-nav layout for dashboard-style apps:

- Brand mark/logo at the far top-left, linking back to the home/primary
  view.
- Search bar centered in the nav, with a visible keyboard-shortcut hint
  (e.g. ⌘K) next to it.
- Secondary navigation icons (notifications, help/cheat-sheet, diagnostics,
  settings, etc.) grouped at the top-right, immediately followed by a
  profile/account switcher as the rightmost element.

Observed 2026-07-27 (Jobernaut dashboard wireframes): this layout was
iterated on explicitly across several rounds — logo became a favicon image
linking to the dashboard, search was moved from left-aligned to centered,
and a notification-badged follow-ups icon was added to the secondary-icon
group, all confirmed piece by piece.

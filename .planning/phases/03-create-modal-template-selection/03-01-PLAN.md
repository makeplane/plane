**As a** workspace member who can create Projects, **I want to** select and preview a Project Template in the existing create Project modal, **so that** the create request can apply the chosen template without changing the normal no-template flow.

Purpose: give later UI plans a typed template catalog fetch and typed optional template_id create path while preserving D-19, D-20, D-21, no backend schema work, and no package additions.
Output: project-template types, project create payload type, template catalog fetch key, ProjectService catalog method, and typed ProjectService/ProjectStore create signatures.
</objective>

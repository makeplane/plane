# Phase 03 - UI Design Contract

> Visual and interaction contract for the Project Template selector in the existing create Project modal. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property          | Value                                                                                                                                               |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| Tool              | none - use existing Plane UI design system                                                                                                          |
| Preset            | not applicable                                                                                                                                      |
| Component library | `@plane/ui` dropdown primitives; prefer `CustomSearchSelect` or an equivalent Headless UI Combobox matching its classes when state slots require it |
| Icon library      | `@plane/propel/icons`; use `ProjectIcon` for the selector button and `ChevronDownIcon` for disclosure                                               |
| Font              | `Inter Variable`, via `font-body` from `packages/tailwind-config/variables.css`                                                                     |

Source: codebase scan found no `components.json`; Plane already uses `@plane/ui`, `@plane/propel`, Headless UI Combobox, and semantic Tailwind tokens.

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage                                                                                   |
| ----- | ----- | --------------------------------------------------------------------------------------- |
| xs    | 4px   | Icon-to-label gap, option internal micro gaps                                           |
| sm    | 8px   | Cover button horizontal/vertical padding, dropdown search input padding, option gap     |
| md    | 16px  | Dropdown side clearance on mobile, option content max line spacing, list section rhythm |
| lg    | 24px  | Minimum touch comfort around compact controls when space allows                         |
| xl    | 32px  | Dropdown minimum row height for template options                                        |
| 2xl   | 48px  | Maximum vertical safety inset from viewport edges                                       |
| 3xl   | 64px  | Reserved; not used by this compact selector                                             |

Exceptions: the cover button may use Plane's existing `h-7` height (28px) to match compact header controls; interactive hit area must remain at least 28px high on desktop and must not drop below 32px on mobile when implemented outside Plane's existing button primitive.

## Typography

Use exactly these sizes and weights for this phase. Do not introduce display typography or new tracking.

| Role               | Size                                          | Weight      | Line Height |
| ------------------ | --------------------------------------------- | ----------- | ----------- |
| Button label       | 13px (`text-body-xs-medium` or `text-13`)     | medium 500  | 1.4         |
| Option name        | 13px (`text-body-xs-medium` or `text-13`)     | medium 500  | 1.4         |
| Option description | 11px (`text-caption-sm-regular` or `text-11`) | regular 400 | 1.4         |
| Inline state text  | 11px (`text-caption-sm-regular` or `text-11`) | regular 400 | 1.4         |

Allowed weights: regular 400 and medium 500 only. Existing modal headings and CTA typography are unchanged.

## Color

Use semantic Plane tokens, not hardcoded hex values. The listed split describes this component's surfaces and states.

| Role            | Value                                                                                  | Usage                                                                                          |
| --------------- | -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------- |
| Dominant (60%)  | `bg-surface-1`, `text-primary`                                                         | Dropdown panel background, option names, search field text                                     |
| Secondary (30%) | `bg-layer-2`, `border-subtle`, `border-subtle-1`, `text-secondary`, `text-placeholder` | Cover button chip, search input, option descriptions, empty/loading text, borders              |
| Accent (10%)    | `bg-accent-primary`, `text-accent-primary`, `border-accent-strong`                     | Existing create Project primary CTA; small inline `Retry` action text/focus only               |
| Destructive     | `text-danger-primary`, `bg-danger-primary`                                             | Destructive actions only; not used in Phase 03 because this selector has no destructive action |

Accent reserved for: existing create Project submit button, keyboard focus-visible ring where the local primitive requires an accent token, and the inline `Retry` action in the dropdown error state. Do not use accent to highlight selected templates, template provenance, badges, group headers, or option rows.

The cover button sits on the cover image. Use a compact `bg-layer-transparent`/translucent chip that keeps text readable over cover imagery, with `text-on-color` when placed directly over darkened cover content or `text-secondary` when rendered on an opaque `bg-layer-2` chip. Hover must use the matching transparent or layer hover token already used by Plane controls.

| Element                  | Copy                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------- |
| Primary CTA              | Keep existing create Project CTA copy unchanged (`Create project` where currently rendered) |
| Selector default label   | `Template`                                                                                  |
| Selected selector label  | Selected template `name`, truncated with ellipsis                                           |
| Search placeholder       | `Search templates`                                                                          |
| Clear option             | `No template`                                                                               |
| Loading state            | `Loading...`                                                                                |
| Empty state heading      | none                                                                                        |
| Empty state body         | `No templates available`                                                                    |
| Error state              | `Could not load templates`                                                                  |
| Error action             | `Retry`                                                                                     |
| Destructive confirmation | none - no destructive actions in this phase                                                 |

Copy rules: do not add `No description` fallback text; when a template has no `description`, render only its name. Do not add warning copy when switching templates before submit. Do not add built-in/custom badges, group labels, or counts.

## Interaction Contract

### Placement And Button

Use the existing `ProjectTemplateSelect` stub rendered by `ProjectCreateHeader` at the top-left of the cover image. Do not move the selector into the form body or create a mobile-only alternate location.

Button contract:

| Property       | Value                                                                |
| -------------- | -------------------------------------------------------------------- |
| Shape          | Compact chip button, max radius `rounded-md`; no pill styling        |
| Size           | `h-7` desktop; at least `h-8` on mobile if a custom button is needed |
| Width          | Auto width with `max-w-[160px]` desktop and `max-w-[140px]` mobile   |
| Content        | `ProjectIcon` 14-16px, label, optional `ChevronDownIcon` 12px        |
| Overflow       | Label uses `truncate`; icon and chevron never shrink                 |
| Default label  | `Template`                                                           |
| Selected label | Template name only, truncated                                        |

The selected template must be visible only through this button label. Do not add a separate selected-template row, banner, badge, checkmark-only summary, or form field.

### Dropdown

Open a simple searchable dropdown from the button using `bottom-start` placement. It must work on desktop and mobile.

Dropdown sizing:

| Viewport | Width                              | Max Height                       |
| -------- | ---------------------------------- | -------------------------------- |
| Desktop  | 280px target, min 240px, max 360px | 320px list area                  |
| Mobile   | `min(320px, calc(100vw - 24px))`   | `min(384px, calc(100vh - 96px))` |

Panel styling must match Plane dropdowns: `rounded-md`, `border-[0.5px] border-subtle-1`, `bg-surface-1`, `py-2.5`, vertical scrollbar when needed, z-index consistent with existing dropdown portals.

Search input:

| Property    | Value                                                                   |
| ----------- | ----------------------------------------------------------------------- |
| Location    | Top of dropdown, inside panel                                           |
| Placeholder | `Search templates`                                                      |
| Icon        | Existing `SearchIcon` from `@plane/propel/icons`                        |
| Styling     | `text-11`, `border border-subtle`, `rounded-sm`, transparent background |

### Options

`No template` is always the first option. It clears selection, closes the dropdown, and causes submit to omit `template_id`.

Template options show:

| Element                    | Contract                                                                              |
| -------------------------- | ------------------------------------------------------------------------------------- |
| Name                       | One line, `text-primary`, 13px medium, truncate                                       |
| Description                | Up to two lines, `text-secondary`, 11px regular; omit the element entirely when empty |
| Counts                     | Do not render                                                                         |
| Built-in/custom provenance | Do not render                                                                         |
| Group headers              | Do not render                                                                         |
| Badges                     | Do not render                                                                         |

Option row spacing: `px-2 py-1.5`, minimum 32px height when name-only, 48px target when description is present. Hover/keyboard active row uses `bg-layer-transparent-hover`. The selected row must not render a persistent checkmark or selected-color treatment because the selected state is represented only by the cover button label.

### State Matrix

| State                    | Visual Contract                                                                                     | Interaction Contract                                                                                                |
| ------------------------ | --------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------- |
| Closed, no selection     | Button shows icon plus `Template`                                                                   | Submit creates a no-template Project                                                                                |
| Closed, selected         | Button shows icon plus selected template name, truncated                                            | Submit includes `template_id`                                                                                       |
| Open, loading            | Dropdown contains pinned `No template` and light `Loading...` text                                  | User can choose `No template`; submit outside dropdown still creates no-template Project if no template is selected |
| Open, empty              | Dropdown contains pinned `No template` and `No templates available` in `text-placeholder`           | No-template creation remains available                                                                              |
| Open, error              | Dropdown contains pinned `No template`, inline `Could not load templates`, and small `Retry` action | No toast; retry refetches list; no-template creation remains available                                              |
| Open, results            | Search filters template rows by name and description; `No template` remains available               | Selecting template closes dropdown and updates button label                                                         |
| Reopen create modal      | Button resets to `Template`                                                                         | Do not persist prior template selection                                                                             |
| Change selected template | New selection replaces local state immediately                                                      | No confirmation or warning                                                                                          |

### Accessibility

The button must be a real `button type="button"` with an accessible name. Use `aria-label="Select project template"` when no template is selected and `aria-label="Selected project template: {name}"` when selected.

Keyboard behavior must match Headless UI Combobox conventions: Enter/Space opens, Arrow keys move active option, Enter selects, Escape closes without changing selection, Tab leaves the control. Focus-visible styling must be visible against cover imagery and dropdown surfaces.

Loading and error text should be announced by normal dropdown focus order or `role="status"` if using a custom state slot. Do not block the modal or trap focus outside the dropdown.

## Form And Data Contract

| Area                       | Contract                                                                                              |
| -------------------------- | ----------------------------------------------------------------------------------------------------- |
| State owner                | `CreateProjectForm` local React state                                                                 |
| Existing `templateId` prop | Ignore in Phase 03                                                                                    |
| Initial modal state        | Always no template on each newly opened create modal                                                  |
| Payload without selection  | Omit `template_id` entirely                                                                           |
| Payload with selection     | Merge `template_id: selectedTemplate.id` into the existing create Project payload                     |
| Store                      | Do not add transient selector state to MobX Project store                                             |
| Service                    | Fetch templates through the existing service layer, not inline `fetch`                                |
| Success behavior           | Keep existing success toast and feature-selection step unchanged                                      |
| Failure behavior           | Keep existing create Project failure toasts unchanged; template list failures stay inline in dropdown |

The template list endpoint is `/api/workspaces/<slug>/project-templates/`. The selector consumes `id`, `name`, and `description` for Phase 03 UI. Other fields may be typed for correctness but must not be shown in this dropdown.

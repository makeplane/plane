## Phase Goal

**As a** workspace member who can create Projects, **I want to** select and preview a Project Template in the existing create Project modal, **so that** the create request can apply the chosen template without changing the normal no-template flow.

<objective>
Deliver the selector UI and create-form happy path for Phase 03 using the typed contracts from Plan 03-01.

Purpose: connect the Phase 01 catalog endpoint and Phase 02 optional template_id backend contract to the existing frontend create modal while preserving D-01 through D-12 and D-18 through D-22.
Output: compact selector UI, local selected-template form state, modal-open reset behavior, and submit-time template_id wiring.
</objective>

## Trust Boundaries

| Boundary                            | Description                                                                                                        |
| ----------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Browser -> Plane API                | Template catalog fetch and Project create submit cross from untrusted browser state into authenticated API routes. |
| API data -> React render            | Template names/descriptions returned from the API are rendered inside the dropdown.                                |
| Modal-local state -> create payload | Selected template state is merged into the Project create request.                                                 |

## STRIDE Threat Register

| Threat ID | Category               | Component                               | Severity | Disposition | Mitigation Plan                                                                                                                                                                |
| --------- | ---------------------- | --------------------------------------- | -------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| T-03-03   | Tampering              | `CreateProjectForm` submit payload      | medium   | mitigate    | Submit only the selected catalog item's backend-provided `id` and keep backend Phase 02 availability validation authoritative; do not add client-side role/template filtering. |
| T-03-04   | Information Disclosure | `ProjectTemplateSelect` error rendering | medium   | mitigate    | Error-state hardening is handled in Plan 03-03 with generic inline catalog failure copy and no response-body rendering.                                                        |
| T-03-05   | Cross-Site Scripting   | Template description row                | medium   | mitigate    | Render template name and description as plain React text, never as HTML or markdown.                                                                                           |
| T-03-SC   | Tampering              | npm/pip/cargo installs                  | high     | mitigate    | No package-manager install tasks are allowed in this plan; use existing catalog/workspace dependencies only.                                                                   |

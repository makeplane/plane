## Phase Goal

**As a** workspace member or admin, **I want to** create Projects with or without a selected Project Template, **so that** Project creation produces useful structure without partial state.

<objective>
Deliver the first complete template creation path: creating a Project from a built-in template persists template states, labels, modules, cycles, starter issues, and relation rows in one transaction.

Purpose: This plan satisfies CREATE-03, CREATE-04, GEN-01..GEN-07, and VER-02 for built-in templates while enforcing D-01, D-04, D-05, D-07, and D-09..D-17.
Output: Template availability resolution, template payload application service, apply-service tests for all three built-ins, and app-route contract coverage for built-in template Project creation.
</objective>

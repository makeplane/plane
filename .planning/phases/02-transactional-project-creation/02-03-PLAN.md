## Phase Goal

**As a** workspace member or admin, **I want to** create Projects with or without a selected Project Template, **so that** Project creation produces useful structure without partial state.

<objective>
Harden template Project creation around invalid availability, custom template use, stale payload validation, dangling references, rollback, and full backend verification.

Purpose: This plan closes CREATE-05, VER-03, and VER-04 while proving the complete Phase 2 goal remains intact for no-template, built-in-template, and custom-template creation.
Output: Edge-case tests, resolver/error handling hardening, rollback tests for template application, and final backend verification commands.
</objective>

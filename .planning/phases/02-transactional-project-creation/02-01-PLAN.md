## Phase Goal

**As a** workspace member or admin, **I want to** create Projects with or without a selected Project Template, **so that** Project creation produces useful structure without partial state.

<objective>
Introduce the shared transactional Project creation service and preserve the no-template user path before template application is added.

Purpose: This plan protects CAT-02 and CREATE-02 while opening the API contract for CREATE-01. It implements D-03, D-06, and D-08 without changing no-template response behavior.
Output: A service-owned create transaction used by both app and v1 create endpoints, optional template_id serializer input, and regression tests for no-template creation and rollback.
</objective>

## Trust Boundaries

| Boundary                     | Description                                                                                     |
| ---------------------------- | ----------------------------------------------------------------------------------------------- |
| client-to-project-create-api | Untrusted POST body enters DRF serializers on app and v1 project create routes.                 |
| api-to-database              | Validated create data crosses into Project, ProjectIdentifier, ProjectMember, and State writes. |
| api-to-celery                | Post-commit activity payload leaves the request transaction for async processing.               |

## STRIDE Threat Register

| Threat ID | Category          | Component                                                              | Severity | Disposition | Mitigation Plan                                                                                                                             |
| --------- | ----------------- | ---------------------------------------------------------------------- | -------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| T-02-01   | Tampering         | `ProjectSerializer.template_id`, `ProjectCreateSerializer.template_id` | medium   | mitigate    | Validate `template_id` as UUID or null and reject blank input before service writes per D-03.                                               |
| T-02-02   | Tampering         | `create_project_with_optional_template` no-template branch             | high     | mitigate    | Wrap Project, ProjectIdentifier, memberships, and DEFAULT_STATES in transaction.atomic per D-06; rollback tests must prove no partial rows. |
| T-02-03   | Denial of Service | `model_activity.delay` callback                                        | medium   | mitigate    | Register activity with `transaction.on_commit(..., robust=True)` so broker failure does not return 500 after committed core data per D-08.  |

# Bug list

Bugs found in a code review of the Plane base code at commit `618d0eb746`. A second reviewer checked each one against the code. Most were confirmed by reading the code rather than by running it.

Line numbers refer to that commit, so they may have moved. Critical and High bugs are not listed here because they have their own pull requests, and some findings are tracked separately.

**256 bugs in the Plane base code:** 90 Medium, 166 Low.

**86 bugs in the code Nexus adds on top of Plane:** 19 Medium, 67 Low, in the sections named "Nexus:" at the end of this file. These were reviewed separately, and each was re-checked by reading the code at `preview` `74111238e`. The Critical and High bugs in that code have their own pull requests, #30 to #39.

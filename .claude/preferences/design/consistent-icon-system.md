# One consistent icon system per app

Use exactly one icon system throughout an entire app or site — pick one
icon library or one hand-drawn SVG style and use it everywhere. Never mix
emoji with a proper icon set, and never mix multiple icon styles across
different sections or pages of the same product. If a spot-check turns up a
mismatched icon (e.g. an emoji left in as a placeholder), it gets swapped to
match the rest of the app — it does not stay as a one-off exception.

Observed 2026-07-27 (Jobernaut dashboard wireframes): emoji were used as a
placeholder icon set across nav and action buttons; once flagged ("this
emoji breaks the design as navbar items have a different style of icons"),
every emoji across every page was replaced with a single consistent
stroke-SVG icon set, including icons that hadn't been called out directly.

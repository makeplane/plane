# Plane Planning Copilot: Execution Plan

Phases: 0 Contracts and data foundation, 1 Streaming backend and chat shell, 2 Widget framework, 3 Tool implementations, 4 Hardening. Each phase is one table with the same columns.

All tasks must follow the "Hard Requirements (Codebase Conformance)" section of `requirements.md`. "Depends on" lists the tasks that must be done first.
